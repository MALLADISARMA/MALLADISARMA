## 🚀 Featured Projects

> Built with production practices in mind: modular architecture, automated testing, containerization, CI/CD, and observability.

### 🛡️ SecureLLM – Local-First AI Prompt Security Gateway

An AI security gateway designed to analyze and protect LLM applications against malicious prompts, prompt injection, jailbreak attempts, sensitive data exposure, and other AI-related threats.

- **Intelligent Threat Detection:** Uses semantic classification to identify malicious prompts and categorize security risks.
- **AI Security Guardrails:** Analyzes incoming prompts and enforces security policies before forwarding permitted requests to a local LLM.
- **Local LLM Integration:** Supports local model inference with a local-first AI architecture.
- **REST API Architecture:** Built with FastAPI and Pydantic for structured request validation and backend communication.
- **Security Monitoring:** Maintains prompt analysis history using Redis and provides a React-based dashboard for visualizing security results.
- **DevSecOps Integration:** Docker-based deployment, automated CI/CD workflows, and Trivy vulnerability scanning.

**Tech:** Python, FastAPI, React, Redis, Hugging Face Transformers, LLMs, Docker, GitHub Actions, Trivy, REST APIs

### 🤖 SQL AI Query Generator

Converts natural language questions into optimized, validated SQL queries so non-technical users can work with databases safely.

- LLM-powered query generation with schema-aware prompting and query validation guardrails.
- Supports query optimization and result retrieval through a clean API layer.
- Containerized with Docker for consistent deployment.
- **Tech:** Python, SQL, NLP, Generative AI, LLMs, Docker
